#   id: <slug>                     saves and keys
#   tier: street | den | orvel | nyx | nolimits
#   event: <Alley.Events name>     the splash knobs: era cap, splash size, skill, Elo range
#   opens: alley | <table name>    with the alley, or once that table is cleared
#   gate: <key>                    a profile.Seen key the table also needs (No Limits: "nolimits", the wall)
#   bases: <deck>, <deck>, ...     the base decks regulars are built from (fixed; the harness checks them)
#   splash-elo: <n>                the measured splash gain, for bracket odds and the panel's Elo
#   headliners: <id>, <id>         the table's two headliners, in order
#   closer: <base>                 the 4th seat while no headliner of the table is ready: this base, a full splash, skill 1.0
#   pool: <build>, <build>, ...    No Limits: the builds its seats 1-3 rotate through (every build sits once before any twice)
#   champions: <build>, <build>    No Limits: the end chair (the first ready unbeaten closes; the next one wildcards)
#   elo: <min>-<max>               No Limits: the window its ready builds must rate in (AlleyData.Problems)
#   seat: <n> <kind> ...           an authored seat (orvel, nyx and nolimits tiers): kind regular | headliner | authored | pool |
#                                  champion; "| as-built": a rated roster deck seated as built (exempt from the exclusion check,
#                                  shown at its own Elo)
#   ready: no                      the table stays locked ("Coming soon") until its authored decks are built
#   mat: <mats.txt key>            music: <Sfx theme>
#   headliner: <id>                starts a headliner: handle:, deck:, table:, list:, over:, pieces:, stakes:, ready:
#   build: <pilot id>              starts a No Limits peak build (docs/dev/NO-LIMITS-SPEC-2026-11-02.md section 10.1): the headliner's
#                                  keys plus base: (its decks/history base), family: (tags; no two sharing one sit at seats 1-3
#                                  together), wave:, restored: (its own banned cards back at 3; over: holds the picks and any
#                                  restored card above its list). A name holding a comma ("Blaster, Dragon Ruler of Infernos") is read whole.
#   bracket: <name>                starts a bracket: kind:, size:, opens:, entry:, pay:, packs:, tokens:, final:, field:
#                                  a field line "| after: <table>" sits once that table is cleared; before, it's one more regular
#                                  from the "splash ... cleared" line (CPUs count the same both ways)
#   handle: <card name> | <prefix> a regular's handle prefix when that card is its best splash
#   names: <name>, <name>, ...     first names for handles (names: lines add up)
