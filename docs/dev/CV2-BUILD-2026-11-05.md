## Owner rules (bugs if broken)

- Every DP change through `Profile.Spend`/`Earn` with a ledger kind; nothing DP-positive. No premium for originals (D5).
- Old saves load: the three copy fields are optional trailing fields (9.2); no `version` bump, no new line kinds.
- Real cards and real sets: a copy's text comes from a real printing's date. No printing is ever invented (D6: no grant).
- Determinism: printings picked from seeds use `Hash.Mix` on the existing seed, never a shared `Random` (risk 5). Pack
  contents, odds and listings must not change; only the stamp is new.
- CPUs untouched: phase 2 changes no CPU deck or playbook.
- Tuning is parked (2026-11-05): no difficulty or deck measuring. Economy correctness checks (`--arbitrage`, the pack-EV
  comparison) still run.
- Commit nothing. Never touch `vendor/ygopro-core`, `build/play-alley`, `build/rework-economy`, `build/qa-night5`.

## The reprint fix (must land before any copy is stamped)

ygoprodeck files the 25th Anniversary Edition reprints (2023-04-20) of Sangan, Catapult Turtle and Witch of the Black
Forest (MRD), Imperial Order and Inspection (PSV) and Toon World (SRL) under the 2002 set name with the same code, and
Stronghold the Moving Fortress's 2013 DPYG reprint under its 2009 code. Dated by set name they'd read as originals that
never existed. C1 decides the fix from the data (an override table of set code + rarity → date, or dropping the
reprint rows a source can tell apart), documents where it came from, and adds a `--texts-check` assertion that none of
those printings can stamp an original. If the 2002 and 2023 rows are indistinguishable in the data, the source that
picks the printing decides: a 2002 booster's pull is the 2002 printing; anything picking "the newest printing" must not
take a 2023 reprint as dated 2002.
