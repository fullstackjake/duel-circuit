## First on the Windows PC

1. Pull, then fetch the submodules with LF endings (see `docs/BUILDING.md`, "Build on Windows"):
   `git -c core.autocrlf=false submodule update --init`. Never commit `vendor/ygopro-core`.
2. Harness: `dotnet build src/Ygo.Harness -c Release`, then `--texts-check`, `--campaign-test`, `--deckbuilding-test`
   and `--games 3`. All four passed on the Mac at `6bdd122`.
3. Build the Windows game (BUILDING.md, "Build on Windows"). `build/windows` is the game the owner plays on the PC:
   build check copies into `build/qa-<name>` unless the owner asks for `build/windows`.
4. **Run `-typecheck` on the Windows build.** This is the one check that has never run on Windows and matters most: the
   fonts' fallback chain is per platform. Its log says which font draws each fallback character (the symbols in
   `unity/Assets/Resources/glyph-corpus.txt`). A box or a missing symbol on Windows is the thing to look for. The spec's
   plan B is in its section 3.
5. Then `-layoutcheck`, `-plaincheck`, `-editorcheck` and `-campaigncheck` at 1280x720 and 1920x1080. On the Mac they
   log 89, 38, 74 and 356 passed steps with none failed. App runs need absolute paths for `-mods`, `-logFile` and the
   check folder, a fresh `-mods` per run, one run at a time. A no-picture run needs `-pics <empty folder> -hdpics off`
   if the PC has card pictures where the game looks for them.
6. Look at the screenshots, not only the logs: the main menu, the campaign screen, the deck editor, a pack reveal, the
   board with a callout, a long prompt.

## Traps met this session

- **Card pictures are found automatically on the Mac** (`CardArt.cs`, FindEdoproPics). No-picture checks need
  `-pics <empty folder> -hdpics off`. Check what the PC finds before trusting a "no pictures" run.
- **The built app reads its own mods folder**, not the repo's. Checks always pass `-mods`, so the real save is never
  written. On the Mac the owner's save loaded fine from a copy (EVIDENCE-2026-11-21c.md).
- **A check's `ok` is not a look.** R3's first build passed 40 runs while foil covered names and pictured editor tiles
  had no readable name. The independent review and opened screenshots found both.
- **Never `rm -rf` a path built from a shell variable** that may be empty. An agent wiped its own check outputs that way.
- **LF endings.** The campaign code and tests match on `"\n"`; a CRLF checkout breaks them.
- **`timeout` doesn't exist on macOS**; on Windows use Git Bash for the commands in the docs.
