## Work notes

[`dev/`](dev/) holds the project's internal working notes: dated specs, plans, QA reports and session handoffs. They
record how things were decided and built, and may be out of date. When a note and the code disagree, the code is
right. Start with the newest `HANDOFF-*.md` and [`dev/TODO.md`](dev/TODO.md).
